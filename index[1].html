04Méthode

D'où viennent les chiffres.

Un observatoire indépendant, transparent sur ses sources et ses limites. Les données officielles sont récupérées par API ; les estimations sont signalées comme telles.

Taux officiel

Les cours de référence de la Banque d'Algérie, récupérés via l'API Frankfurter qui agrège les sources officielles. Actualisation quotidienne, série mensuelle depuis 2015.

Source : Frankfurter · Banque d'Algérie

Marché parallèle

Le « square » n'a pas de cotation officielle. Les valeurs affichées sont une estimation calibrée sur les primes observées, ajustable via le curseur. À titre indicatif uniquement.
